# 实时地图操作说明

地图作为主要工作区，右侧操作面板独立滚动。桌面可拖动中间分隔条调整面板宽度，也可收起面板或进入全屏。窄屏采用地图在上、操作面板在下的布局。

## 常用操作

- 路况：按名称、OSM 编号搜索路段或交汇点，叠加通行状态或拥堵筛选。列表点击会定位并选中；地图点击只打开编辑器，不改变当前视角。路况按相邻交汇点或端点分段编辑。
- 司机：选择车辆查看上报的定位和当前导航路线。车辆可能已经停止上报，定位记录不等于在线状态。无定位时不以导航起点代替当前位置。
- 导入：获取 GCC 内 OSM 道路，在面板筛选并一键勾选或从地图虚线选择。切换到其他面板会隐藏预览命中层并保留勾选。已有道路进入路况编辑，已删除道路进入恢复确认。
- 恢复：分别恢复删除的路段或整条道路；整条道路恢复时保留独立删除的路段。
- 动态：道路事件、施工活动和禁行区管理。

图层菜单可控制道路、交汇点、司机位置、选中司机导航和禁行区。司机路线显示于道路路况上方，车辆标记继续显示在路线之上。

选择路段后，侧栏显示编辑范围、实时司机数量和路况。拥堵阈值与备注位于高级设置。名称及几何是整条道路的操作，与当前路段路况分开显示。删除保留原来的确认与恢复流程。

路况每 15 秒更新，刷新保留当前地图视角、搜索条件和未保存表单。切换 GCC 会清理旧区域选择和导入预览。

## 地图旋转

缩放按钮右侧提供无级旋转控制：按住 ↻ 左右拖动，或拖动 0–360° 滑杆，地图实时跟随任意角度，不按固定步长吸附。触屏支持双指旋转地图。N 按钮显示一位小数的角度（只对显示取舍，地图保留完整精度），点击后沿最短方向平滑恢复正北；系统偏好减少动画时直接复位。拖动采用指针捕获，移出按钮仍可继续调整，并按动画帧合并更新。键盘可在旋转按钮上用方向键调整，Home 恢复正北。旋转保持中心点和缩放级别；自动刷新、图层切换继续保留方向。底图、道路、交汇点和导航矢量共用旋转容器，车辆标记及提示仍保持直立。旋转只改变视图，不修改道路坐标。

采用 leaflet-rotate 0.2.8（GPL-3.0），源码固定在 addon/utils/leaflet-rotation.js，并保留上游许可证。来源：https://github.com/Raruto/leaflet-rotate。使用显式安装函数适配 Ember 模块及当前 Leaflet 实例；关闭插件自带控制，由组件提供中文控制。单行箭头使用独立标记容器，避免位置重复旋转。
